# 인물 여정 확장 · 수정8

Character에서 인물을 선택하면 관련 장소와 해당 인물의 여정 목록이 표시됩니다.
00은 전체 순차 재생, 개별 번호는 해당 파트만 재생합니다. 인물 해제 또는 탭 변경 시 진행 중인 재생과 정지 대기도 취소됩니다.

## 구성
- 케이건 6개: 기존 kagan.js 유지.
- 티나한 6개 / 비형 6개 / 륜 8개 / 사모 8개 / 갈로텍 6개: character-journeys.js.
- 기존 사건 원본은 변경하지 않고 경로를 복사하여 인물 상징색을 적용합니다.
- 공통 표시기 rescue.js에 순차 단계(stages), 위치 사건, 영역 표시, 정지(pauseMs), 다른 인물 사건 연결을 추가했습니다.

## 이번 확정 사항
- 사모·마루나래 조우: [col:48,row:39]. 기존 사모 경로의 한계선 내부 칸입니다. 사용자 승인에 따른 표시용 임의 위치이며 원작의 정밀 좌표가 아닙니다.
- 갈로텍: 초기 남부군 경로를 따라 엔거·카시다·세퀴라도로 이동한 뒤 유료도로행 개인 경로로 분리합니다. 군대와 다른 단일 인물 화살표를 씁니다.
- 갈로텍 06: 유료도로→시모그라쥬 점선, 륜과 조우 후 1.3초 정지, 하텐그라쥬 이동. 운영체제 동작 줄이기 설정에서는 정지 대기를 생략합니다.
- 사모 08: 하텐그라쥬 위치 사건만 표시하며 접근 경로를 만들지 않습니다.
- 티나한/비형 06의 연결 버튼은 다른 인물을 추가 선택하여 동일 장면을 해당 인물 관점으로 엽니다.
- 복수 선택 시 경로 간격과 위치 사건 글자 높이를 달리합니다. 표시 간격은 실제 동선 차이가 아닙니다.

## 편집
character-journeys.js의 item은 제목·소제목·설명·단계·관련 사건 순서입니다.
move는 이동, at은 장소 사건, regionCells는 상고토 영역, related는 인물 간 연결입니다.
원문을 추가 확인하면 설명을 보완하되 기존 사건 원본과 인물별 이동을 함께 점검하세요.

구출대 개별 경로와 쇼자인테쉬크톨 위치 사건의 기존 동작 확인. 브라우저 오류 없음.
