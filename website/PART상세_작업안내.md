# 수정15 — 여정별 상세 내용

구출대 8개, 쇼자인테쉬크톨 11개, 대확장 전쟁 10개 단계에 설명을 추가했습니다.

단계를 누르면 기존 경로와 함께 여정 목록 아래의 상세 영역이 갱신됩니다. 번호·제목, 한 문장 요약, 사건 내용, 인물과 역할, 관련 장소를 제공합니다. 00에는 전체 요약과 기록 범위를 표시하고 전투 지점만 보기에도 별도 안내를 제공합니다.

## 편집
- js/part-details-data.js: 29개 원고. summary(요약), body(본문), related(인물 ID/이름 및 역할), places(장소 ID)
- js/part-details.js: 독립 상세 영역과 인물·장소 연결
- css/part-details.css: 여정 목록과 상세 영역 간 여백
- rescue.js, war.js: 단계 선택 시 새 표시기를 호출하고 탭 전환 시 초기화. Character 여정은 기존 동작 유지.

장소 클릭은 아래의 장소 상세를 열며 PART 설명은 유지됩니다. 인물 클릭은 Character 소개를 엽니다. 관련 장소를 누른 것만으로 다른 경로를 재생하지 않습니다.

기존 좌표·경로·단계 수·사모의 경로는 변경하지 않았습니다. 탈피 구간은 특정 지점으로 단정하지 않으며 수장 영역은 정확한 피해 범위로 확정하지 않습니다. 조사된 독자 자료와 기존 승인 설명을 요약한 원고로, 원작 쪽수 검증은 미완료입니다.

검증: 29개 단계 선택과 번호 표시, 전체 요약, 장소 상세 후 PART 유지, 인물 소개 연결, 사건 변경 초기화, 구출대 기존 경로 생성. 콘솔 오류 없음.
