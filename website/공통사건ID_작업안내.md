# 공통 사건 ID 및 인물별 행동 — 수정22

## 적용 기준

문장 일치를 기준으로 공통색을 판단하던 방식에서 명시적으로 등록한 사건 ID 방식으로 변경했습니다. 같은 좌표, 같은 사건 ID, 공통 요약 병합 허용, 실제 도착해 표시 중인 서로 다른 인물이라는 조건을 모두 만족할 때만 합칩니다. 등록하지 않은 사건은 문구가 같아도 임의로 합치지 않습니다.

## 기준표

| ID | 사건 | 지도 표시 |
| --- | --- | --- |
| rescue-assembly | 마지막 주막 구출대 집결 | 케이건·티나한·비형 공통 요약 |
| samo-collapse | 사모 가사상태 진입 | 륜·사모 공통 요약 |
| samo-coronation | 대호왕 추대 | 케이건·사모 공통 요약 |
| goddess-rescue | 여신 구출 작전 | 케이건·티나한·비형 공통 요약 |
| bihyung-rescue | 티나한의 비형 구출 | 티나한·비형 공통 요약 |
| murun-encounter | 무룬강 조우 | 같은 사건으로 연결하되 5인의 개인 행동·색상을 각각 유지 |
| kagan-revelation | 케이건의 정체와 폭주 | 여신 구출과 구분한 케이건 개인 사건 |

같은 장소에 있다는 이유로 하텐그라쥬 탈출·전쟁 준비·여신 구출·정체/폭주를 합치지 않습니다. 한 인물만 표시하면 인물색, 공통 요약이 실제로 둘 이상 표시되면 공통색 #C5CED3입니다. 선택 해제 시 다시 판정합니다.

## 편집 위치

- js/occurrence-catalog.js: 사건 ID, 장소, 공통 요약명, 병합 여부, 인물별 역할.
- js/kagan.js 및 js/character-journeys.js: 각 위치 사건의 eventRef 연결.
- js/rescue.js: 도착 후 표식 생성, 사건 ID 검증, 우측 패널의 연결 사건/개인 역할 표시.
- js/character-labels.js: 공통 요약 병합과 기존 충돌 회피 배치.

표시 문장을 고칠 때는 label이나 기존 개인 badge를 수정합니다. 같은 사건이면 ID를 유지합니다. 새로운 장소나 다른 시점의 사건은 별도 ID를 사용합니다. 장소·참여자 불일치가 있으면 안전하게 개인 표시로 처리합니다.

## 추가 표시

케이건01과 비형02는 기존 주막 도착 경로 뒤에 집결 위치 사건을 추가했습니다. 케이건02에도 무룬강의 개인 행동 표식을 추가했습니다. 케이건06은 기존 도착 이동 뒤 여신 구출 공통 요약과 정체·폭주 개인 사건을 구분해 표시합니다. 이동선 좌표와 기존 개인 설명은 보존했습니다.

우측 상세에는 기존 설명을 유지하며 연결 사건명과 선택 인물의 역할을 함께 제공합니다. 위치만 표시하는 단계에는 불필요한 선 그리기 대기를 추가하지 않습니다. 선 그리기 875ms 및 전체 재생 파트 간격 1초는 유지합니다.

## 검증

- 모든 사건 참조의 장소·참여자 유효성 검사 및 전체 JS 문법 통과.
- 인물 6명의 기존 routes 배열, 원래 사건·격자·사모 전쟁 경로·높새바람 탑·상고토·재생 설정 보존 비교 통과.
- 공통 요약/개인 행동/다른 사건/미등록 문구/잘못된 장소·참여자 판정 검사 통과.
- 브라우저에서 주막 경로 진행 중 미표시, 도착 후 3인 집결 공통색, 선택 해제 시 인물색 복원 확인.
- 륜·사모의 가사상태와 티나한·비형의 구출 사건 공통 표시 확인.
- 무룬강 5인 행동은 같은 ID 아래 5개의 개인색 문구 유지.
- 여신 구출 3인 공통 요약과 케이건 정체·폭주 개인 문구 분리 확인.
- 휴대폰 390×844에서 위 공통/개인 문구의 겹침과 가로 넘침 없음. 기존 Event 금색 표식과 Place 소개 연결 확인. 콘솔 오류 없음.

원작 정보나 경로를 새로 추정한 작업이 아니라 승인된 여정의 사건 연결과 표시 기준을 정리한 작업입니다. 실제 모바일 기기·Safari 검증은 별도입니다.
