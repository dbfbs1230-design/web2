# 사모 페이 전쟁 경로 수정 — 수정21

## 최신 사용자 확정 순서

가사상태 진입 → 회복 후 대호왕 추대 → 시구리아트 유료도로 통과 → 엔거평원 전투 합류 → 북부군과 동일 경로로 남부군 추적 → 하텐그라쥬에서 케이건과 대면.

‘대호황’은 기존 작품/사이트 표기인 ‘대호왕’으로 정리했습니다.

## Character

사모는 기존 01~06을 유지하며, 07 유료도로 통과, 08 엔거평원 전투 합류, 09 북부군과 함께 남부군 추적, 10 케이건과 대면으로 구성했습니다. 엔거평원 이후에는 WAR_DATA의 북부군07/08/09 좌표를 참조합니다. 별도 추정 우회선을 만들지 않았습니다.

사모의 기존 즈믄누리 도착선과 인물 여정의 즈믄누리 마커를 제거했습니다. 가사상태/추대와 마지막 심장탑 대면은 별도 위치 사건이며 추가 내부 이동선이 없습니다.

## Event

전쟁05의 사모 선은 유료도로에서 끝납니다. 06에서는 유료도로에서 엔거평원 전투 대표 지점으로 이동합니다. 상세 경유지가 제공되지 않았으므로 이 연결만 점선으로 표시합니다. 07~09는 북부군과 같은 좌표의 사모 개인선을 함께 보여주되 소폭 표시 간격으로 구별합니다. 실제 길이 달라졌다는 의미가 아닙니다.

공통 장소 상세, PART 설명, 사모 소개도 함께 갱신했습니다. 즈믄누리는 비형의 출발/북부 협력 거점으로 유지하며 사모의 전쟁 도착지로 설명하지 않습니다. 기본 7곳과 Place 14곳 목록은 유지합니다.

## 보존

높새바람 탑 부근 행적과 추격 경로, 상고토 수장 영역과 기존 설명을 유지합니다. 다른 인물/군대 경로, 전투 도착 판정, 875ms 공통 속도와 1초 파트 간격, 복수 설명 색상 조건은 그대로입니다.

## 검증

- 사모10개 파트/유료도로 종점/엔거 합류 점선/엔거 이후 북부군 좌표 일치 검사 통과.
- 다른 군대/인물의 경로, 상고토 영역, 탑 상세·추격 원본 불변 검사 통과.
- JS 전체 문법과 기존 재생시계 검사 통과.
- 브라우저에서 사모05~10 표시/남진4개 이동선과 각 도착 사건/마지막 위치 사건의 이동선0개 확인.
- 이벤트05~09 PART와 경로 선택 확인. 콘솔 오류 없음.

## 추가 검증 제안 — 아직 추가 경로 확정 아님

1. 유료도로→엔거평원 상세 경유지: 현재는 확정된 출발/도착만 점선 연결합니다. 원작 근거 또는 사용자 경로 시안이 확인되면 구체화합니다.
2. 세퀴라도 공방전과 사모의 이동 시점: 기존 공방전 소개에는 대호왕의 항전이 있지만 새 개인 경로는 하인샤→유료도로부터 시작합니다. 두 설명을 연결하는 시점과 생략 구간은 원문 대조 후 보완하며 이번 작업에서는 별도 세퀴라도 개인선을 만들지 않습니다.

위 두 후보는 이번 코드 수정만으로 원작 검증 완료로 보지 않습니다. 높새바람 탑과 상고토는 사용자의 유지 지시를 우선합니다.
