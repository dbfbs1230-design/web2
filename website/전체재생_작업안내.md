# 전체 경로 재생 조작 — 수정16

구출대 파견, 쇼자인테쉬크톨, 2차 대확장 전쟁에서 **00 전체 경로**를 선택하면 사이드 패널의 탭 바로 아래 재생 조작부가 나타납니다.

- **일시정지 / 재개**: 경로의 진행 위치, 전투 표식 효과, 상고토 영역 효과, 다음 단계까지의 대기 시간을 함께 정지·재개합니다.
- **처음부터**: 현재 사건의 누적 경로와 결과를 초기화하고 PART 01부터 재생합니다. 일시정지 상태에서도 새로 재생합니다.
- **이전 파트 / 다음 파트**: 앞선 파트의 결과를 완성 상태로 복원하고 선택한 파트부터 시작합니다. 일시정지 중 이동하면 정지 상태를 유지합니다. 첫/마지막 파트에서 범위 밖 버튼은 비활성화합니다.
- **현재 PART**: 상단에 번호·제목·상태를 표시하고 여정 목록에서 해당 파트를 강조합니다. 아래 PART 상세도 함께 바뀝니다. 자동 스크롤은 하지 않으며 상단 제목을 누르면 상세로 이동합니다.
- 각 파트 종료 후 2초 동안 내용을 읽을 시간을 줍니다. 마지막 단계 후에는 전체 경로를 유지하고 재생 완료 상태를 표시합니다.
- 장소 상세를 열면 일시정지합니다. 사건·탭 변경, 선택 해제, 개별 PART 선택은 전체 재생을 종료합니다.

## 수정 위치

- `js/playback.js`: 공통 재생 시계와 재생 상태, 조작부. `2000`은 파트 종료 후 대기 시간(ms)입니다.
- `css/playback.css`: 고정 조작부, 현재 단계 강조, 상세 이동 시 상단 여백.
- `js/rescue.js`, `js/war.js`: 기존 경로 표시기를 공통 재생 시계에 연결합니다. 추격은 기존 공용 표시기를 사용합니다.
- `js/part-details.js`: 자동 재생 시 강제 스크롤 없이 상세를 갱신할 수 있도록 선택 사항을 추가했습니다.
- `js/location-details.js`: 장소를 열 때 전체 재생을 멈춥니다.
- `index.html`: 추가 파일 연결 및 수정 파일 캐시 버전 갱신.

기존 좌표·사건 원고·이동경로 데이터·인물 여정·인트로 디자인은 유지했습니다. Character의 전체 경로에는 이번 조작부를 적용하지 않습니다.

## 실행 및 업로드

압축을 풀어 `website/index.html`을 Chrome으로 열거나 VS Code Live Server로 실행합니다. GitHub Pages에는 website 폴더 안의 파일과 assets/css/js 폴더를 함께 업로드합니다.
