# 제2차 대확장 전쟁 추가본

전체 website 폴더를 사용합니다. index.html을 Chrome 또는 VS Code Live Server로 실행하세요.

## 메뉴
- 00 전체 경로: 01~10을 순차 재생하고, 이동선·도착한 전투·상고토를 누적 유지합니다.
- 01~10: 선택한 파트만 재생합니다. 다른 파트나 사건 선택 시 진행 중 재생을 취소합니다.
- 전투 지점만 보기: 14개 표식(엔거평원 6칸 포함)만 표시합니다. 이동선과 상고토 영역은 숨깁니다.

## 확정한 처리
- 카시다로 지명을 통일했습니다. 인물 이름은 기존 데이터의 갈로텍을 사용합니다.
- 05 갈로텍은 세퀴라도에서 유료도로까지 이동합니다. 슈라도스에서 출발한 남부군은 엔거평원까지 이동하며 여기에는 아직 북부 승리 표식이 없습니다.
- 06 남부군 후퇴 후 북부군이 도착하면 엔거평원 6칸에 북부 승리 표식이 나타납니다.
- 03 자보로·슈라도스·카시다 표식은 해당 경로가 위치에 도착할 때 나타납니다. 뒤이어 상고토가 아래에서 위로 채워집니다.
- 08, 09는 후퇴와 진격을 순서대로 표시합니다. 09 갈로텍 우회와 10 공동경로는 점선입니다.

## 코드 수정 위치
- js/war-data.js: places(장소), parts(10개 파트), stages(파트 안의 순서), routes(동시 이동), battleAt(도착 전투), sangoto(영역 칸).
- js/war.js: 전쟁 전용 재생 및 UI. 기존 rescue.js와 독립되어 구출대·쇼자인테쉬크톨을 변경하지 않습니다.
- index.html: 위 두 파일 연결만 추가했습니다.

stages는 순서대로 실행하고, 한 stage의 routes는 동시에 실행합니다. battleAt의 id는 places의 id와 같아야 하며 해당 좌표가 route.points에 있어야 합니다. front는 엔거평원 여섯 칸 전투를 한 번에 표시하는 예외입니다.

북부군 #39BFFF / 남부군 #FF946A는 굵은 선과 이중 화살촉입니다. 갈로텍 #CE5E39는 단일 화살촉입니다. 점선은 동선 미확인을 뜻합니다.

첨부 시안의 도식 경로를 좌표로 옮겼습니다. 상고토는 시안에서 판독한 칸 외곽을 따른 영역이며 원작의 정밀 지리 경계가 아닙니다. 사건 설명은 사용자 제공 내용을 정리한 것으로 별도 원작 대조 검증을 수행한 자료는 아닙니다.
