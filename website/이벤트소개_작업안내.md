# 수정14 — 이벤트 소개

세 이벤트를 선택하면 기존 여정 위에 사건명, 유형·목적, 한 문장 설명, 개요, 관련 인물, 대표 장소, 기록 범위, 자료 안내가 표시됩니다.

- js/event-profiles-data.js: 소개 원고. related에는 핵심 인물 ID 또는 조연 이름과 역할을, places에는 기존 장소 ID를 입력합니다.
- js/event-profiles.js: 소개 표시 및 기존 인물·장소 상세 연결
- css/character-profiles.css: 기존 캐릭터 소개 스타일을 그대로 공유합니다.
- index.html: 위 두 스크립트 추가

인물명은 해당 Character 소개로 이동합니다. 마루나래·시우쇠·라수는 별도 여정이 없어 일반 텍스트입니다. 대표 장소를 누르면 기존 장소 상세를 열며 이동경로를 자동 재생하지 않습니다.

기존 단계 목록, 경로, 사모의 이동, 기본 거점, 표지는 유지했습니다. 초기 단계의 ‘수탐자 파견’ 명칭도 이번 소개 추가에서는 변경하지 않았습니다. 쇼자인테쉬크톨의 가사상태는 사이트의 기록 범위로 설명하며 풍습 자체의 종료 조건과 구분합니다.

원작 인용이 아닌 요약이며, 세부 원작 본문·쪽수 대조는 미완료입니다. 장식용 화살표는 추가하지 않았습니다.
