# 주요 거점 탭 — 수정18 작업 안내

## 사용 방법

index.html을 Chrome에서 열거나 VS Code의 Live Server로 실행합니다. 파일을 일부만 옮기지 말고 전체 website 폴더를 함께 사용하세요.

우측 상단의 Place · 거점 탭에서 14개 장소를 선택합니다. 선택하면 기존 인물·사건 소개와 같은 글꼴·제목·구분선 양식으로 장소 소개, 주요 사건, 관련 인물, 자료 안내를 제공합니다. 관련 사건 제목과 핵심 인물 이름은 기존 탭으로 연결됩니다. 이전·다음 경유지는 추가하지 않았습니다.

기본 7개는 상시 표시합니다. 나머지 7개는 Place에서 선택한 한 곳만 표시하며 다른 장소를 선택하거나 해제하거나 다른 탭으로 이동하면 사라집니다. 추가 마커는 기존 주막·탑·피라미드·조우 기호를 사용하며 지도 칸 크기를 따릅니다. 장소 선택으로 경로를 자동 재생하지 않습니다.

## 편집 위치

- js/place-catalog-data.js: 14곳의 종류·한 문장 소개·본문·추가 자료 안내.
- js/location-data.js: 공통 주요 사건·관련 인물·출처. 기존 내용을 그대로 공유합니다.
- js/place-catalog.js: 목록·소개·추가 마커 표시.
- css/place-catalog.css: 기존 스타일을 공유하기 위한 최소 보정.
- js/app.js: 세 번째 탭과 독립 장소 선택 상태, 세 탭 키보드 이동.
- js/landmarks.js: 기존 기본 마커를 Place 선택 상태와 연결.

## 보존한 내용

원래의 구출대·추격·전쟁 경로와 지도 격자, 인물 여정, 재생 제어 파일은 변경하지 않았습니다. 사모 경로와 좌표를 새로 확정하지 않았습니다. 장식 화살표도 추가하지 않았습니다.

## 원고 정리

기본 7곳: 하인샤 대사원, 즈믄누리, 하텐그라쥬, 최후의 대장간, 자보로, 세퀴라도, 시구리아트 유료도로.
추가 7곳: 마지막 주막, 무룬강 조우 지점, 두억시니의 피라미드, 높새바람 탑, 라호친, 시모그라쥬, 엔거 평원.

최후의 대장간 중복 등록을 제외했습니다. 하인샤를 여신 구출 결말 장소로 설명하던 앞선 제안의 잘못된 표현은 넣지 않았습니다. 나가 도시들은 독립적이므로 하텐그라쥬를 나가 전체의 수도로 단정하지 않습니다. 자료 안내에 독자 편집 자료의 한계를 유지합니다. 탑 근처 사모 행적을 설명하더라도 기존 사모 이동선은 변경하지 않습니다.

## 검증 결과

- JavaScript 전체 문법 검사와 기존 공통 재생 시계 자동 검사 통과.
- 14개 레코드, 기본 7개, 공통 장소 ID와 원래 좌표 참조 검사 통과.
- 원래 구출대/추격/전쟁/격자/인물여정/재생 파일이 수정 전과 동일함을 비교 확인.
- 앱 내 브라우저에서 14곳 모두 소개 표시 및 기본/선택 마커 수 확인.
- 사건·인물 링크 전환, 기존 세 사건의 개별 파트 표시와 Place로 전환 시 숨김 확인.
- 선택 토글·선택 해제·기본 마커 선택 강조 초기화 확인.
- PC 1440×900, 휴대폰 390×844, 태블릿 820×1180, 가로 844×390에서 가로 넘침 및 탭 폭 확인.
- 키보드 세 탭 순환과 End 이동, 소개 포커스·스크롤 확인. 확인 중 콘솔 오류 없음.
- 실제 모바일 기기와 Safari 검증은 수행하지 않았습니다.

일반 Headless Chrome 실행은 환경에서 종료되어 앱 내 브라우저로 검증했습니다. 미리보기 탭을 결과물로 유지하는 표시는 자동 승인 검토에서 차단되어 생략했습니다. 업로드·배포는 하지 않았습니다.
