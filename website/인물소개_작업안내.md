# 수정11 — 인물 소개

Character에서 인물을 선택하면 기존 여정 위에 이름, 종족, 역할, 한 문장 설명, 작품 내 역할, 주요 관련 인물이 표시됩니다.

## 수정할 파일
- `js/character-profiles-data.js`: 6명 소개 원고와 관련 인물, 참고 자료 주소
- `js/character-profiles.js`: 소개 화면 생성 및 관련 인물 연결
- `css/character-profiles.css`: 소개 영역의 글자·간격·색상
- `index.html`: 위 파일 불러오기
- `js/location-details.js`: 장소 본문에서 인물을 선택하면 소개 제목으로 이동하도록 연결

핵심 인물 6명의 이름을 누르면 해당 인물의 소개와 여정으로 이동합니다. 기존 복수 선택은 유지됩니다. 조연은 설명만 표시합니다. 소개 아래에서 기존 여정을 그대로 선택할 수 있습니다.

소개 데이터의 `species`는 종족, `role`은 역할, `summary`는 한 문장 설명, `body`는 소개 본문, `related`는 관련 인물과 관계, `source`는 참고 주소입니다. 관련 인물 이름은 기존 인물 데이터의 이름과 일치할 때 링크가 생성됩니다.

조사 자료는 독자 편집 위키이며 원작 본문·쪽수 대조가 완료된 자료는 아닙니다. 한 문장 설명은 사이트용 요약입니다. 자료 안내에서 근거를 확인할 수 있습니다.

기존 표지, 좌표, 사건 및 인물 이동경로 데이터는 변경하지 않았습니다. 이전·다음 경유지 기능도 추가하지 않았습니다.

전체 폴더를 유지한 채 index.html을 열거나 VS Code의 로컬 서버로 확인하세요. GitHub Pages에는 폴더 안의 파일을 기존과 같은 구조로 업로드하면 됩니다.
