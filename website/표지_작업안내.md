# 픽셀 눈 표지 · 2026-10-12

검은 배경 위에 흰 정사각형 눈이 오른쪽에서 왼쪽 아래로 흩날립니다. 중앙 문구와 로고, 클릭하여 지도에 입장하는 기능은 유지합니다.

## 수정 위치
- `js/intro-snow.js`: 눈 크기(size), 밝기(alpha), 바람(vx), 낙하 속도(vy), 입자 수를 수정합니다. vx는 음수일 때 왼쪽으로 이동합니다.
- `css/style.css` 마지막 표지 리뉴얼 영역: 검은 배경, 문구와 입장 안내의 스타일입니다.
- `index.html`의 intro 영역: 중앙 문구, 로고, 입장 안내입니다.

눈은 화면 크기에 맞춰 그려지고 지도 입장 및 비활성 탭에서는 멈춥니다. 운영체제의 동작 줄이기 설정에서는 정지된 눈으로 표시합니다.
기존 인트로 SVG와 data.js의 이미지 목록은 보관하지만 현재 표지에서는 사용하지 않습니다. README의 기존 슬라이드 교체 안내보다 이 안내가 우선합니다.
