# 쇼자인테쉬크톨 추가 및 수정 3차

## 실행
전체 website 폴더를 사용합니다. index.html을 Chrome 또는 VS Code Live Server로 실행합니다.

## 이번 변경
- 구출대의 중복 합류 파트를 삭제하고 이후 번호를 당겨 01~08로 정리했습니다. 00도 이 목록을 재생합니다.
- 경로에 어두운 그림자를 추가했습니다. 종점은 실제 마커 도형의 외곽 바로 앞에서 멈춥니다.
- 인트로 세 장은 center top으로 정렬합니다. 기존 화면 채우기 방식은 유지하므로 화면 비율에 따라 아래쪽 일부는 잘릴 수 있습니다.
- 쇼자인테쉬크톨 00~11을 추가했습니다. 마지막 주막과 즈믄누리는 이 사건에 표시하지 않습니다.

## 경로 및 표시
01 륜 이동 / 02 사모 추격 / 03 무룬강 조우·1차 추적 실패 / 04 륜 탈피 구간(피라미드→탑) / 05 륜 자보로 / 06 사모 자보로 / 07 륜 유료도로 / 08 사모 유료도로 / 09 륜 하인샤 / 10 사모 하인샤 / 11 사모 가사상태 진입.
03과 11은 금색 위치 사건 표식이며 새 이동선을 추가하지 않습니다. 00에서는 앞서 표시한 경로를 유지합니다. 사모의 자보로행은 시안처럼 탑을 경유하지 않는 서쪽 길입니다.

## 이후 수정할 파일
- js/pursuit-data.js: 쇼자인테쉬크톨 장소 설명, 단계, 경로 points, 색, offset. 사용자 시안을 옮긴 도식이며 원작 정밀 동선 검증 자료는 아닙니다.
- js/rescue-data.js: 구출대 파견 장소·단계.
- js/rescue.js: 두 사건이 공유하는 선택·재생·마커·화살표 처리. createEventJourney가 사건별 독립 레이어를 만듭니다.
- js/data.js: 인트로 이미지 정렬 position.

사모의 offset [-0.35,0.35]는 겹친 선을 구분하기 위한 시각적 간격입니다. 실제로 다른 지리 좌표를 이동했다는 의미가 아닙니다. 세부 시간과 사건 설명은 후속 요청으로 보완합니다.
