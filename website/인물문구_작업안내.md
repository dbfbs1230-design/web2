# 인물 문구 겹침 및 색상 — 수정19

## 수정 내용

- 인물 위치 사건의 지도 문구에 인물명과 사건명을 함께 표시합니다.
- 글자는 ARCHIVE_DATA.characters의 메인 컬러를 사용합니다. 갈로텍 글자도 인물 탭의 메인 컬러를 따르며 기존 이동선 색은 변경하지 않습니다.
- 먼저 표시된 글자부터 배치하며 이전 자리가 비어 있으면 유지합니다. 새 문구는 기존 문구, 현재 보이는 거점 이름·표식, 지도 도구와 화면 경계를 피해 배치합니다.
- 위치와 경로 좌표는 그대로 두고 글자만 이동합니다. 가는 안내선은 원래 거점과 문구를 연결하며 이동경로와 구별됩니다.
- 긴 지도 문구는 축약하며 SVG title과 기존 우측 설명에 전체 내용을 유지합니다. 공간 부족 시 인물명으로 줄여 다시 배치합니다. 화면 밖 사건은 다시 화면 안에 들어올 때 문구를 표시합니다.
- 인물 여정 파트의 우측 상세 제목도 해당 인물 색으로 표시합니다. 공통 장소명과 설명 본문은 중립색을 유지하며, 인물 관점으로 연 장소 상세에서는 관련 사건 제목만 인물 색으로 강조합니다.
- 사건 탭의 기존 금색 위치 사건 표식·문구는 유지합니다.

## 편집 위치

js/character-labels.js: 공통 사각형 충돌 검사와 배치, 긴 문구 축약, 안내선.
js/rescue.js: 인물 문구의 생성 및 인물별 제목 색상.
css/rescue.css: 문구 가독성을 위한 얇은 어두운 외곽 처리.
js/data.js: 기존 여섯 인물의 메인 컬러 기준.

## 성능과 기존 기능

지속적인 반복 애니메이션 없이 문구/마커 생성·삭제, 선택 변경, 확대·이동, 화면 크기 변경, 이름에 포커스/포인터가 닿을 때 검토합니다. 같은 프레임의 요청은 하나로 합칩니다. 숨겨진 탭에서는 예약된 배치를 취소합니다. 경로의 매 프레임 화살표 이동은 감시하지 않습니다.

원래 사건 경로·좌표·격자, 인물 여정 데이터, 공통 재생 제어, 거점 탭 데이터는 변경하지 않았습니다. 새로운 외부 라이브러리나 이미지도 추가하지 않았습니다.

## 검증

- 전체 JS 문법 검사, 기존 공통 재생 시계 검사 통과.
- 18개 사각형의 겹침 회피·화면 경계·기존 배치 우선 유지 순수 함수 검사 통과.
- 원래 구출대/추격/전쟁/인물여정/격자/상태/재생 데이터 불변 비교 통과.
- 앱 내 브라우저에서 여섯 인물의 위치 사건 동시 표시, 인물별 글자 색상, 문구 간 겹침 0건 확인.
- 휴대폰 390×844에서 여섯 문구 모두 표시, 화면 이탈 0건·겹침 0건·가로 넘침 없음. 130% 확대 후에도 겹침 0건 확인.
- 사건 탭의 쇼자인테쉬크톨11은 기존 금색 유지. Place 장소 소개, 인물 탭 복귀와 사건 표식 제거 확인. 확인 중 콘솔 오류 없음.
- 실제 모바일 기기 및 Safari 검증은 별도입니다.
