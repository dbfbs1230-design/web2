# 수정17 — 디버깅 및 최적화

## 유지한 내용

사건/인물 원고, 격자 좌표, 모든 이동경로 데이터, 색상, 인트로 눈보라 컨셉을 유지했습니다. 서버나 프레임워크를 추가하지 않았으며 기존처럼 index.html 또는 Live Server로 실행합니다.

## 발견하고 수정한 오류

1. 전투 표식에는 기본 마커용 좌표 속성이 없는데 지도 확대 코드가 일괄 변환하여 NaN 좌표가 될 수 있었습니다. 기본 마커만 갱신하고 전투/사건 마커는 각 표시기가 담당하도록 분리했습니다.
2. 일시정지 후 다음 파트로 이동하면 첫 프레임 전 화살촉 좌표가 undefined일 수 있었습니다. 생성 시 시작점과 각도를 초기화합니다.
3. 일시정지 중 RAF를 계속 예약하던 코드를 제거했습니다. 중단 시 실제 예약을 취소하고 재개 시 남은 시간부터 이어갑니다.
4. 지도에서 표지로 돌아가도 인물 경로 애니메이션이 진행될 수 있었습니다. 표지 또는 숨겨진 브라우저 탭에서는 모든 여정 시계를 동결합니다. 전체 재생은 표지로 돌아갈 때 사용자 일시정지 상태로 남습니다.
5. 화면 크기 변화가 무조건 확대 배율을 초기화하던 부분을 개선했습니다. 회전/주소창 높이 변화 시 상대 확대 배율을 유지하며 위치 제한을 다시 적용합니다.

## 성능 개선

- Pretendard 전체 파일 2,057,688바이트 → 현재 원고용 118,292바이트. 원본 전체 폰트는 새 글자가 추가될 때 자동 보완하도록 남겨 두었습니다.
- 로고 1697×927 PNG 대신 800px 폭 무손실 WebP(37,888바이트)를 사용합니다. 원본은 보존합니다.
- 지도는 1040/2080/4160px 해상도를 표시 폭과 화면 배율에 따라 선택합니다. 각각 53,542 / 116,594 / 338,176바이트입니다. 좌표계는 계속 4160×3016이며 SVG와 같은 변환을 공유합니다.
- 초기 HTML 참조 파일 합계(캐시·전송압축 제외): 약 2.91MB → 0.48MB, 약 83% 감소. 추가 확대 이미지/미포함 글자 폰트 다운로드는 별도입니다. ZIP에는 원본과 예비 자산도 포함되므로 이 수치를 ZIP 크기와 혼동하지 마세요.
- 1040px 지도의 RGBA 디코딩 크기 이론값은 약 3.14MB로 기존 50.19MB의 1/16입니다. 실제 브라우저 프로세스 메모리는 이미지 캐시·GPU·브라우저 구현에 따라 다릅니다.
- 경로 프레임에서는 현재 화살촉과 노출 길이만 갱신합니다. 전체 마커·선 두께·그림자는 경로 생성 또는 배율 변경 시 갱신합니다.
- 드래그/휠 변환은 화면 프레임당 한 번으로 합칩니다. 같은 배율의 단순 이동 시 반복되는 마커 갱신을 생략합니다.
- 표지 눈은 평상시 30fps, 입장 눈보라 60fps를 목표로 합니다. Canvas 버퍼는 최대 약 200만 픽셀로 제한하며 표지가 보이지 않을 때 1×1로 반환합니다.
- 단계 사이 2초 대기는 RAF 반복 대신 중단 가능한 타이머로 처리합니다. 정지·백그라운드 상태에서는 애니메이션 시계에 예약된 RAF/타이머가 없습니다.

## 화면별 배치

스마트폰 세로는 상단 지도/하단 상세, 세로 태블릿(701~1024px)은 넓은 상단 지도/하단 상세, PC·가로 태블릿은 좌우 배치를 사용합니다. 낮은 가로 화면은 지도와 310px 상세 패널을 나란히 배치합니다. 모바일 재생 버튼의 높이는 44px 이상입니다.

## 검증 방법과 한계

공통 시계 테스트는 `node tools/check-playback.cjs`로 재실행합니다. 정지·재개·백그라운드 동결·타이머 남은 시간·리셋·효과 취소를 검사합니다. 모든 JS 문법과 기존 데이터/좌표 보존을 검사했습니다.

브라우저의 스마트폰·태블릿·PC 크기에서 레이아웃, 확대, 파트 선택/재생, 상세 연결 및 콘솔 오류를 검토했습니다. 실제 iPhone/iPad/Android 하드웨어의 발열·배터리·Safari 메모리 측정은 수행하지 않았습니다. 실제 기기에서 최종 발표 전 한 번 더 확인하는 것이 좋습니다.
