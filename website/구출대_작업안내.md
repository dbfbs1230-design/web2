# 구출대 파견 추가본

기존 app.js, data.js, grid.js, style.css는 그대로입니다. index.html에는 새 파일 3개를 연결하는 부분만 추가했습니다. 전체 폴더를 사용하면 됩니다.

## 실행
index.html을 Chrome으로 열거나 VS Code의 Live Server로 실행합니다. GitHub Pages에는 website 폴더 안의 파일과 폴더를 함께 올립니다.

## 동작
1. Event → 구출대 파견: 주요 장소 9개만 먼저 표시합니다.
2. 우측의 01~09 파트 선택: 해당 구간만 약 0.65초 동안 화살표 방향으로 그립니다. 다른 파트를 누르면 이전 경로를 교체합니다.
3. 지도 아이콘 선택: 우측 아래 상세 정보가 해당 장소로 바뀝니다. 키보드 Tab/Enter도 사용할 수 있습니다.
4. Character 또는 다른 사건으로 이동: 구출대 전용 표식과 경로를 숨깁니다.
5. ‘구출대 파견의 표식’을 펼치면 기호와 경로 색상의 의미를 확인합니다.

## 수정할 곳
- js/rescue-data.js: places의 name/description/col/row, parts의 title/caption/description, routes의 points/color/name.
- js/rescue.js: 선택 동작, 화살표 애니메이션. duration의 650이 밀리초 단위 속도입니다.
- css/rescue.css: 전용 패널·표식·선 스타일.

격자는 0부터 세며 오른쪽이 col 증가, 아래가 row 증가입니다. 경로 points는 [[col,row], ...] 순서이며 마지막 점이 화살표 도착점입니다. 지도 전체 보기·확대·이동과 무관하게 칸 좌표는 유지됩니다.

## 사용자 확정 사항
- 작은 주황색 Illustrator 패스 흔적은 데이터에서 제외합니다.
- 케이건의 마지막 주막/높새바람 탑 사이 연결은 미확정 동선입니다. certainty: 'uncertain' 점선으로 유지하고 01에서 비형의 출발과 동시에 표시합니다.
- 륜과 구출대 3인의 선이 겹치는 칸을 합류 지점으로 등록했습니다.
- 상세 사건 설명은 사용자 제공 순서를 반영한 초안입니다. 원작 검증 완료 자료로 취급하지 않습니다. 경로 꺾임점은 제공된 시안을 격자에 옮긴 도식입니다.

## 수정 2차
- `00 전체 경로`: 01~09를 누적 재생합니다. 재선택하면 처음부터 재생하며 다른 파트를 선택하면 즉시 해당 구간으로 바뀝니다.
- 01의 케이건 점선에서 [47,37], [46,38]을 제거했습니다. [46,39] 이후 주막 방향만 남깁니다.
- 장소 표식이 지도 칸과 함께 확대·축소됩니다.
- LOCATION과 범례가 겹치지 않도록 우측 패널 내 내용 높이를 보존했습니다.
- 인트로 3장은 사용자 제공 SVG로 교체했습니다. 파문의 강한 테두리를 제거했습니다.
- 수정한 파일의 URL 뒤 버전 값은 오래된 캐시 방지용입니다. 향후 파일 교체 시 버전 값을 올려 주세요.
