# 재생 속도와 선택 조건별 색상 — 수정20

## 공통 속도

js/playback.js 상단 JOURNEY_TIMING에서 routeMs=875, partGapMs=1000으로 관리합니다.

기존 인물/일반 사건 경로 650ms와 전쟁 경로 1100ms의 중간값인 875ms를 두 표시기에 공통 적용했습니다. Event 전체 재생만 가지고 있던 파트 사이 2000ms 대기는 1000ms로 줄이고 Character 전체 재생에도 같은 1000ms를 적용했습니다. 각 파트 내부의 별도 서사상 정지는 유지합니다. 같은 시간에 그리는 선의 길이가 다르면 화면상의 이동거리도 다릅니다. 이번 변경은 기존 도식의 선 그리기 시간을 통일한 것이며 거리 비례 물리 속도로 변경한 것은 아닙니다.

## 사용자 if 조건

- 한 인물만 해당 장소의 사건 설명을 표시: 그 인물의 메인 컬러.
- 여러 인물이 선택되어도 표시 중인 설명이 서로 다름: 각각의 인물색.
- 같은 좌표 + 같은 사건 문구(띄어쓰기 차이는 무시)를 실제로 표시 중인 복수 인물: 하나의 문구로 묶고 공통색 #C5CED3.
- 합쳐진 문구는 참여 인물 이름을 모두 표시.
- 일부 인물 선택 해제/파트 변경/탭 변경: 조건을 다시 검사하고 필요하면 남은 인물색으로 복원.
- 단순히 같은 장소라는 이유만으로 다른 사건까지 합치지 않음. 아직 그 사건에 도착하지 않은 인물을 미리 공통 그룹에 포함하지 않음.

지도 글자뿐 아니라 인물 위치 사건의 사각형 테두리도 인물색/공통색으로 맞췄습니다. 기존 금색 고정 테두리 때문에 단독 인물도 공통 표시처럼 보이던 부분을 함께 수정했습니다. 사건 탭 자체의 금색 위치 사건 표식은 유지합니다.

## 검증

- 단독/동일 설명 복수/다른 설명/다른 좌표 그룹 판정과 전체 JS 문법 검사 통과.
- 기존 공통 시계 정지·재개·숨김·예약 취소 검사 통과.
- 경로/격자/인물 여정/위치 원본 파일 불변 비교와 두 표시기의 공통 시간 참조 확인.
- 앱 내 브라우저: 케이건4 단독 크림색 글자와 테두리, 티나한6 단독 노란색, 서로 다른 사건의 색 분리 확인.
- 같은 하인샤의 대호왕 추대를 표시한 케이건4+사모6은 공통색으로 합쳐짐. 사모 해제 시 케이건 크림색 복원, 반대로 케이건 해제 시 사모 청록색 복원 확인.
- 기존 전쟁01과 Place 하인샤 소개 전환 확인. 콘솔 오류 없음.

원작 좌표, 이동경로, 인물/사건 원고는 바꾸지 않았으며 업로드·배포는 하지 않았습니다.
