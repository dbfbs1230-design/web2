# 수정12 — 기본 주요 거점

기본 지도에 하인샤 대사원, 즈믄누리, 하텐그라쥬, 최후의 대장간, 자보로, 세퀴라도, 시구리아트 유료도로를 표시합니다. 주요 거점 메뉴에서도 선택할 수 있습니다.

- js/landmarks.js: 기존 WAR_DATA의 좌표 참조, 장소 종류·간단한 설명, 마커와 메뉴 및 중복 제거
- css/landmarks.css: 마커·메뉴·지명 표시. 좁은 화면에서는 지명을 선택 시 표시합니다.
- index.html: 확장 파일 로딩과 범례 명칭
- js/app.js: 기본 거점의 크기 처리를 전용 모듈에 맡기는 선택자 변경

거점을 선택하면 간단한 설명과 종류, 기존 주요 사건과 관련 인물을 확인합니다. 장소 선택만으로 경로가 재생되지는 않습니다. 기본 거점과 같은 좌표의 사건 마커는 중복 표시하지 않습니다. 추가 장소는 기존 사건·인물 선택 상태에 따라 나타납니다. 전투 표식은 기본 거점 위에 기존 시점대로 나타납니다.

기존 사모 경로 및 모든 사건·인물 경로 데이터는 변경하지 않았습니다. 주요 거점 목록의 선정과 기본 표시는 사용자 승인 사항입니다.
