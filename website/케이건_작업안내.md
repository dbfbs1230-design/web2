# 케이건 인물 여정

Character → 케이건 드라카 선택 → 00 전체 경로 또는 01~06 선택.
선택 시 관련 장소를 먼저 표시하고, 각 파트 선택 시 해당 경로를 그립니다.

- 데이터/설명: js/kagan.js. rescue-data.js와 war-data.js의 승인된 좌표·경로를 읽어 재사용합니다.
- 03은 구출대 04~08 경로를 연속으로 연결합니다.
- 04는 하인샤의 위치 사건이며 이동선을 만들지 않습니다.
- 01과 06은 미확정 점선을 유지합니다. 모든 개인 경로는 케이건 상징색을 사용합니다.
- 심장탑은 하텐그라쥬 상세 정보로 설명하며 별도 좌표를 만들지 않습니다.
- 공통 표시 모듈 rescue.js에 선택 활성 조건과 제목 옵션만 추가했습니다. 기존 사건 호출은 기존 조건을 그대로 사용합니다.
- 인물 해제/탭 전환 시 레이어와 재생을 정리합니다. 다른 5명의 여정은 이번 작업에 포함되지 않습니다.

검증: 6개 파트·10개 장소 원본 좌표 일치, 전체 순차 재생, 04 이동선 없음, 위치 상세, Event 전환 및 구출대 파트 표시 확인.
