# 주요 위치별 상세 정보 — 수정10

## 추가 범위
- 기존 장소 20개에 소개, 주요 사건 38개, 관련 인물과 자료 안내를 연결했습니다.
- 지도·경로·좌표·표지와 기존 여정 데이터는 유지합니다.
- 이전/다음 경유지 및 별도 이동 버튼은 추가하지 않습니다.
- 설명 속 핵심 인물 6명의 이름을 누르면 Character 탭에서 해당 인물을 활성화합니다. 기존 복수 선택을 유지합니다.
- 사건 제목을 누르면 Event 탭의 해당 사건/파트가 선택되고 기존 경로가 재생됩니다.
- 다른 조연은 이동할 여정이 없으므로 일반 텍스트입니다.
- 현재 사건/인물과 관련된 기록을 먼저 보여줍니다. 전투 표식도 동일 장소 기록에 연결됩니다.

## 편집 파일
- js/location-data.js: 장소 원고. intro, events, people, sources, note를 편집합니다.
- js/location-details.js: 본문 인물 링크와 사건 파트 연결, 표시 순서.
- css/location-details.css: 장소 상세에만 적용되는 스타일.
- index.html: 새 파일 연결. app.js: openEvent API 추가.
- rescue.js / war.js: 장소 선택에서 공통 원고 호출, 사건 링크 수신.

## 자료 구분
독자 편집 자료를 바탕으로 요약했으며 원작 본문·판본·쪽수 대조는 완료하지 않았습니다.
높새바람 탑, 카시다, 슈라도스, 페로그라쥬, 악타그라쥬 일부 설명은 사용자 승인 시안을 기준으로 범위를 제한했습니다.
마루나래 조우 좌표는 승인된 표시용 임의 위치입니다.
상고토의 기존 영역/전쟁 설명은 이번 작업에서 변경하지 않았습니다. 상고토 전체와 판사이 수장 범위의 대조는 별도 보완 대상입니다.
피라미드의 유해의 폭포 조우 시 케이건은 다른 세 인물과 떨어져 있었음을 구분했습니다.
새로운 좌표나 실제 원작에 없는 경유지를 만들지 않았습니다.

## 사용
압축 해제 후 website/index.html을 크롬에서 열거나 VS Code의 로컬 미리보기로 실행합니다.
